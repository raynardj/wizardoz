# Resources

This directory contains optional resources that are NOT compiled into the firmware by default.

## Fonts (`fonts/`)

Custom font files for TFT display text rendering.

### Available Fonts

- **`chinese_16.h`** - A 714KB PROGMEM smooth font supporting Latin + Chinese characters
  - Generated by `tools/create_font.py`
  - Only needed if displaying Chinese text (e.g., Chinese transcriptions)

### Usage

To use a custom font:

1. Copy the desired font from `resources/fonts/` to `src/tft/fonts/`
2. Enable the font in `src/tft/display.cpp`:
   ```cpp
   #define USE_CUSTOM_FONT  // Uncomment this line
   ```
3. Rebuild and flash the firmware

### Why Optional?

Custom fonts consume significant flash space (the Chinese font is ~714KB). 
By making them optional:
- Default builds use the built-in system font (smaller binary)
- Users only include fonts they actually need
- Faster compile times for development

### Creating Custom Fonts

Use the font conversion tool:
```bash
python tools/create_font.py --input your_font.ttf --size 16 --output my_font.h
```

Then place the output in `resources/fonts/` and follow the usage steps above.
